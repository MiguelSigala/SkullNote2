# Skullnote

Miguel Arturo Sigala Dominguez

## Descripción del proyecto

Skullnote es una aplicación móvil diseñada para facilitar el aprendizaje, la práctica y la creación musical mediante herramientas que permiten a los usuarios trabajar con diferentes aspectos de la música desde un solo lugar.

La aplicación está dirigida principalmente a estudiantes de música, principiantes, músicos autodidactas, compositores y personas con conocimientos musicales intermedios.

Su objetivo es centralizar herramientas musicales esenciales en una interfaz accesible, funcional e intuitiva.

## Características principales

- **Afinador:** Permite identificar la frecuencia de las notas captadas mediante el micrófono para ayudar al usuario a afinar su instrumento.
- **Metrónomo:** Permite configurar los BPM, seleccionar compases y personalizar la acentuación de cada pulso para mantener el ritmo durante la práctica.
- **Editor de partituras:** Permite crear, editar y visualizar partituras musicales.
- **Biblioteca de acordes:** Ofrece un catálogo de acordes con diagramas y diferentes posiciones para facilitar su consulta y aprendizaje.

## Tecnologías utilizadas

- React Native: Desarrollo de la aplicación móvil.
- JavaScript / TypeScript: Lenguajes de programación.
- Expo: Entorno de desarrollo y ejecución.
- Node.js y npm: Administración de dependencias y herramientas del proyecto.

## Instalación

Para ejecutar Skullnote en un entorno local, es necesario contar con Node.js, npm y Expo.

1. Clonar el repositorio:

```bash
git clone URL_DEL_REPOSITORIO
```

2. Acceder a la carpeta del proyecto:

```bash
cd Skullnote
```

3. Instalar las dependencias:

```bash
npm install
```

4. Iniciar el servidor de desarrollo:

```bash
npx expo start
```

5. Abrir la aplicación mediante Expo Go o un emulador compatible.

## Alcance del proyecto

La primera versión de Skullnote contempla cuatro herramientas principales: afinador, metrónomo, editor de partituras y biblioteca de acordes.

El desarrollo inicial se enfoca en ofrecer las funciones esenciales de cada módulo, priorizando la facilidad de uso y la experiencia del usuario.

Las funciones avanzadas de colaboración en tiempo real, almacenamiento en la nube, reconocimiento musical avanzado y composición profesional quedan fuera del alcance de esta primera versión.
